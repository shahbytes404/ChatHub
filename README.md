# ChatHub

A real-time messaging application inspired by WhatsApp, Telegram, and Messenger.

ChatHub is designed as a production-style chat system with one-to-one and group conversations, online presence, missed message recovery, delivery/read states, and scalable WebSocket-based message delivery.

For the high-level design (HLD), refer to [Part 1](./Part%201%20%28HLD%29/ChatHub%20-%20HLD.png).
